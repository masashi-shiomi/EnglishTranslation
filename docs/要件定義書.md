# 要件定義書

## サービス概要

ユーザーが登録した英単語や英文法を使用して、アプリ内のAIが自動で英文を生成するサービスです。
生成した英文の横に「日本語訳」を用意し、タップすることで日本語訳を表示できます。

### 4. 英単語及び英文法一覧画面

**アクセス条件**
- ログイン後のみアクセス可能

**主要機能**
- **一覧表示**
  - 英単語と英文法を一覧表示
  - 並び順：アルファベット順
  - 各単語/文法ごとに以下を表示
    - 日本語訳
    - 削除ボタン
    - 編集ボタン

- **切り替え機能**
  - ボタンで英単語と英文法の一覧を切り替え可能

- **追加機能**
  - 入力フォーム（画面の一番下に常時表示）
  - 英単語または英文法を入力
  - 「追加」ボタンをタップするとFirestoreに登録

---

### 5. 英文生成画面

**アクセス条件**
- ログイン後のみアクセス可能

**主要機能**
- **英文生成**
  - 英単語及び英文法一覧画面で登録した単語・文法から1つを選択
  - Claude APIを使用して自動で英文を生成
  - 生成した英文と日本語訳をFirestoreに保存

- **一覧表示**
  - 生成した英文を一覧表示
  - 各英文の横に「日本語訳」を表示
  - 「日本語訳」をタップすると日本語訳を表示/非表示に切り替え
